# Автоматизация API для сервиса Stellar Burgers

Репозиторий содержит пакет автоматизированных API-тестов для проверки бизнес-логики бэкенда Stellar Burgers.

## Технологический стек
* **Язык**: Python 3.11+
* **Тест-раннер**: pytest
* **HTTP-клиент**: requests
* **Отчетность**: Allure Framework

## Структура проекта
* `api/` — изолированные классы-клиенты (`UserClient`, `OrderClient`, `BaseClient`) для отправки HTTP-запросов к ручкам сервера.
* `data/` — константы проекта, URL-адреса эндпоинтов и тексты системных сообщений.
* `helpers/` — вспомогательные утилиты для генерации случайных данных пользователей.
* `tests/` — тестовые сценарии, разделенные по логическим блокам.
* `conftest.py` — конфигурационный файл с pytest-фикстурами для автоматического создания/удаления аккаунтов в рамках тестов.
